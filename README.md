# AK's IT CARE — refreshed multi-page website

## Pages
- `index.html` — home page
- `services.html` — service details
- `about.html` — about and service approach
- `areas.html` — service locations and map
- `contact.html` — contact form (opens WhatsApp)
- `booking.html` — repair request (opens WhatsApp)

## Publish on GitHub Pages
1. Extract this ZIP.
2. Upload the contents of this folder to the root of your `AK-S-IT-CARE` repository (not the outer folder).
3. Commit the changes and allow GitHub Pages to redeploy.
4. Test all page links on mobile and desktop.

## Notes
- The existing logo and app icons are retained.
- Service photos use remote Unsplash image URLs; an internet connection is required for those photos. One original SVG illustration is stored locally.
- Contact forms do not store submissions. They prepare a WhatsApp message for the visitor to review and send.
- Please verify service rates and contact details before publishing.
